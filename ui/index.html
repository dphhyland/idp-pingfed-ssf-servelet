PingFederate as an SSF transmitter + receiver

A real PingFederate 13.0.3 emitting signed Security Event Tokens about what it observes — logouts become CAEP session-revoked, deprovisioning becomes RISC account-disabled — delivered by poll (RFC 8936) and push (RFC 8935). The finale is a loopback: PF pushes a SET to its own receiver, which verifies the signature and revokes the subject's OAuth grants. All calls go through a thin proxy that injects credentials — the browser never sees a secret.
